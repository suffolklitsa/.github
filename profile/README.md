# LITSA at Suffolk Law

The Legal Innovation and Technology Student Association at Suffolk University Law School in Boston.
We run events on the law of technology and build tools for law students and student organizations.

## Repositories

**For students**

- [**course-planner**](https://github.com/suffolklitsa/course-planner): plan your Suffolk Law semesters. Spring schedule builder now (conflicts, credits, requirements), graduation check and career-path survey next. Runs at suffolklitsa.org/planner.
- [**suffolk-guides**](https://github.com/suffolklitsa/suffolk-guides): plain how-to guides for Suffolk systems, subscribable calendar feeds, and a character & fitness kit for your bar application.
- [**ma-lit-bills**](https://github.com/suffolklitsa/ma-lit-bills): a neutral tracker of Massachusetts bills that touch technology, with plain-language summaries.
- [**challenge**](https://github.com/suffolklitsa/challenge): LITSA's annual legal AI challenge: rules, lanes, rubrics, starter kits and scoring tools.

**For LITSA and other clubs**

- [**suffolklitsa.org**](https://github.com/suffolklitsa/suffolklitsa.org): our website, with Boston legal tech events, competitions and resources for Suffolk students.
- [**club-kit**](https://github.com/suffolklitsa/club-kit): tools any student organization can use to run events, make flyers, collect RSVPs and keep a member list.
- [**handbook**](https://github.com/suffolklitsa/handbook): how LITSA's Build work happens, for members with or without coding experience.
- [**design-system**](https://github.com/suffolklitsa/design-system): the colors, type, spacing and components every LITSA project shares.
- **suffolk-chatbot** (private): the Suffolk student assistant, which answers questions about deadlines, courses, clinics and student services from Suffolk's public pages. Build members get access on request.

**New to GitHub?** Start with the [handbook](https://github.com/suffolklitsa/handbook): an account, Codespaces, your first pull request, and how to work with AI coding agents.

**Where to start:** every repo has issues labeled `good first issue` and `no code needed`, each saying what done looks like and where to begin. The [LITSA Build board](https://github.com/orgs/suffolklitsa/projects/1) shows them all.

## Get involved

Suffolk Law students can join the Build committee in the LITSA GroupMe. If you already have a GitHub account,
email sam.darkwa@su.suffolk.edu with your username and we'll add you. New to GitHub? Join Build anyway and we'll get you set up.
