# LITSA at Suffolk Law

The Legal Innovation and Technology Student Association at Suffolk University Law School in Boston.
We run events on the law of technology and build tools for law students and student organizations.

## Repositories

- [**suffolklitsa.org**](https://github.com/suffolklitsa/suffolklitsa.org): our website, with Boston legal tech events, competitions and resources for Suffolk students.
- [**club-kit**](https://github.com/suffolklitsa/club-kit): tools any student organization can use to run events, make flyers, collect RSVPs and keep a member list.

## Get involved

Suffolk Law students can join the Build committee in the LITSA GroupMe. If you already have a GitHub account,
email sam.darkwa@su.suffolk.edu with your username and we'll add you. New to GitHub? Join Build anyway and we'll get you set up.
