# Contributing to LITSA projects

New to GitHub? The [LITSA handbook](https://github.com/suffolklitsa/handbook) walks you through your first pull request and how to work with AI coding agents. Each repo's `AGENTS.md` lists its commands and rules.


1. **Start with an issue.** Pick an open one (look for `good first issue`) or open a new one describing the change.
2. **Work on a branch** and open a pull request against `main`. Small pull requests get reviewed faster.
3. **Describe what changed and how you checked it** in the pull request.
4. **Never commit secrets or personal data.** No API keys, passwords, member rosters, sign-in sheets or email lists.
   Use environment variables for keys and keep member data out of the repository.
5. **Be clear about AI use.** AI tools are welcome. You're responsible for what you submit, so read and test it.

Questions go in the Build topic on GroupMe or to sam.darkwa@su.suffolk.edu.
